# 硬件规划

> 具体型号和 GPIO 尚未最终确认，本文件暂不编造引脚表。

## 已确定模块类别

- ESP32-S3 开发板。
- 红外检测模块。
- 温湿度传感器。
- HX711 与称重传感器。
- OLED 显示屏。
- 电机、驱动模块和出粮机构。
- 独立电机电源及必要的降压模块。

## 接线原则

- 所有通信模块与 ESP32-S3 共地。
- 电机不得直接由 GPIO 驱动。
- 电机电源与逻辑电源分开规划，并满足峰值电流。
- 感性负载需要合适的驱动和保护。
- HX711 和称重传感器远离电机及强干扰走线。
- 首次上电前检查每路电压。
- GPIO 分配确认后再写入正式接线表。

## 标定项目

| 项目 | 标定目标 |
| --- | --- |
| 称重零点 | 空仓时稳定归零 |
| 称重比例 | 使用多个已知重量拟合 |
| 出粮换算 | 电机动作量与实际克数关系 |
| 红外阈值 | 区分短暂经过和有效进食 |
| 余粮百分比 | 空仓与满仓重量映射 |
