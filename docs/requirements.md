# 需求说明

## 1. 项目定位

面向家庭宠物喂养场景，设计一套以 ESP32-S3 为主控的智能喂食器，实现设备控制、定时喂食、进食统计、环境监测、余粮显示和数据智能分析。

## 2. 用户角色

| 角色 | 权限 |
| --- | --- |
| 设备所有者 | 绑定设备、控制出粮、管理计划、查看全部数据 |
| 普通查看者 | 查看设备状态和分析结果，不允许控制出粮 |
| 设备 | 上报传感数据、接收控制指令、反馈执行结果 |
| 服务端 | 身份验证、数据存储、规则判断和大模型调用 |

第一版只实现设备所有者，其他角色保留为后续扩展。

## 3. 功能需求

### FR-01 设备联网

- ESP32-S3 能连接指定 Wi-Fi。
- 断网后自动重连。
- 小程序显示设备在线或离线状态。
- 凭据存储方式在实现阶段确定，不提交真实凭据。

### FR-02 手动出粮

- 用户可在小程序选择出粮克数。
- 服务端限制单次最大出粮量和操作频率。
- 设备返回已接收、执行中、成功或失败状态。
- 实际出粮量优先通过出粮前后重量差计算。

### FR-03 定时出粮

- 支持新增、修改、启用、停用和删除计划。
- 每个计划至少包含时间、目标克数和启用状态。
- 计划需要持久化，设备重启后不丢失。
- 同一分钟内同一计划不得重复执行。

### FR-04 进食次数统计

- 红外传感器检测宠物靠近食盆。
- 连续遮挡达到阈值后才开始一次进食事件。
- 连续离开达到阈值后结束事件。
- 短暂经过、信号抖动和同一次进食中的反复遮挡不重复计数。
- 记录开始时间、结束时间、持续时间和重量变化。

### FR-05 温湿度测量

- 周期采集温度和湿度。
- OLED 和小程序显示最新值。
- 记录采样时间。
- 传感器异常时显示不可用状态，不上传伪造数值。

### FR-06 余粮测量

- 使用称重传感器和 HX711 获取粮仓重量。
- 支持空仓和标准砝码标定。
- 显示余粮克数和百分比。
- 余粮低于阈值时产生提醒。

### FR-07 OLED 显示

OLED 至少显示：

- 余粮克数或百分比。
- 温度和湿度。
- 今日进食次数。
- Wi-Fi 或云端连接状态。
- 必要的设备故障提示。

### FR-08 小程序

- 设备状态总览。
- 手动出粮。
- 定时计划管理。
- 进食记录。
- 温湿度和余粮历史趋势。
- AI 分析结果。
- 控制操作结果提示。

### FR-09 数据分析

- 服务端汇总每日喂食、进食、余粮和环境数据。
- 大模型只接收必要的结构化统计数据。
- 分析结果包含摘要、风险等级和建议。
- 结果保存后由小程序查询，不要求每次打开页面都重新调用模型。
- 模型调用失败不能影响基础喂食功能。

## 4. 非功能需求

### 安全

- API 密钥不得放入小程序或公开仓库。
- 服务端验证用户和设备归属。
- 控制接口设置出粮量、频率和重复请求限制。
- 重要操作保留时间、用户、设备和执行结果。

### 可靠性

- 断网时定时出粮仍可执行。
- 设备重启后恢复计划和校准参数。
- 传感器故障不阻塞电机控制和网络任务。
- 关键任务应设置超时和错误状态。

### 可维护性

- 固件、后端、小程序和硬件资料分目录维护。
- 数据字段和命令格式以协议文档为准。
- 硬件型号、GPIO 和阈值只在确认后写入正式配置。

## 5. 第一版不包含

- 宠物疾病诊断。
- 自动购买宠物粮。
- 摄像头实时视频。
- 多宠物身份识别。
- 商业级支付、订阅和多租户系统。

## 6. 验收原则

每项功能必须同时满足：

1. 有明确输入和预期输出。
2. 能在设备日志或服务端日志中追踪。
3. 能在小程序中看到最终状态。
4. 失败时有可识别错误信息。
5. 有对应测试记录。
