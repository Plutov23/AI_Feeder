# 开发路线图

> 当前只定义阶段和验收条件，不代表已经完成实现。

## 阶段 0：需求冻结

- [x] 建立独立仓库。
- [x] 记录功能范围。
- [x] 建立初始架构和协议。
- [ ] 确定具体传感器、电机、驱动和电源方案。
- [ ] 确定云平台、后端技术和数据库。
- [ ] 确定小程序页面清单。

完成标准：硬件清单和技术选型得到确认，不再依赖未说明的假设。

## 阶段 1：硬件单模块验证

- [ ] ESP32-S3 基础工程和串口日志。
- [ ] OLED 显示。
- [ ] 温湿度采集。
- [ ] HX711 读取和标定。
- [ ] 红外输入与去抖。
- [ ] 电机正转、停止和超时保护。

完成标准：每个模块均有接线记录、测试步骤和测试结果。

## 阶段 2：设备基础功能

- [ ] 统一传感器任务。
- [ ] 手动出粮。
- [ ] 克数与电机动作标定。
- [ ] 红外进食状态机。
- [ ] OLED 状态页面。
- [ ] NVS 保存校准参数和计划。

完成标准：不连接云端也能完成本地定时喂食和进食计数。

## 阶段 3：物联网通信

- [ ] Wi-Fi 配置和重连。
- [ ] 网络校时。
- [ ] MQTT 上报。
- [ ] 命令订阅。
- [ ] command_id 防重复。
- [ ] 执行结果反馈。

完成标准：设备断线重连后不重复执行旧命令，定时功能不受断网影响。
