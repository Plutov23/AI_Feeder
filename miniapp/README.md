# 微信小程序规划

## 页面规划

| 页面 | 内容 |
| --- | --- |
| 设备总览 | 在线状态、余粮、温湿度、今日进食次数 |
| 手动出粮 | 克数选择、确认、执行状态 |
| 喂食计划 | 新增、编辑、启停和删除 |
| 进食记录 | 时间、持续时长和消耗重量 |
| 数据趋势 | 温湿度、余粮和进食统计 |
| AI 分析 | 摘要、风险等级和建议 |
| 设备设置 | 设备信息、提醒阈值和绑定状态 |

## 安全边界

- 小程序不保存物联网平台高权限密钥。
- 所有控制请求发送到业务后端。
- 后端验证微信用户、设备归属和操作权限。
- 出粮按钮需要防重复点击。
- 页面必须区分“请求已提交”和“设备执行成功”。

## 状态设计

控制操作至少展示以下状态：

- 正在提交。
- 设备已接收。
- 正在执行。
- 执行成功。
- 执行失败。
- 设备离线。
- 请求超时。
