# 后端规划

## 职责

- 微信用户身份验证。
- 用户与设备绑定。
- 设备状态查询。
- 手动出粮和计划管理。
- 命令状态追踪。
- 原始数据和统计数据存储。
- 大模型调用、结构化校验和结果缓存。
- 权限、限流、审计日志和错误处理。

## 建议模块

```text
backend/
├── api/             小程序 HTTPS API
├── auth/            用户身份与设备权限
├── iot/             MQTT 或物联网平台适配
├── models/          数据模型
├── analytics/       日、周统计
├── llm/             大模型调用与输出校验
└── tests/           接口和业务测试
```

## 数据类别

- 用户。
- 设备。
- 设备绑定关系。
- 传感器采样。
- 喂食计划。
- 控制命令。
- 命令执行结果。
- 进食事件。
- 日统计。
- AI 分析结果。
- 操作日志。

## 大模型调用原则

- 只发送完成分析所必需的数据。
- 默认发送汇总数据，不发送无关个人信息。
- 要求结构化 JSON 输出。
- 服务端校验字段、类型和枚举值。
- 设置超时、重试次数和调用频率。
- 保存模型版本和生成时间。
- 模型异常不影响设备控制接口。
